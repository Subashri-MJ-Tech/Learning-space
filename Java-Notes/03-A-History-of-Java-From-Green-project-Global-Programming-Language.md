## 📜 Key Highlights of Java's History

### The Green Team Project (1991)
In June 1991, James Gosling, Mike Sheridan, and Patrick Naughton initiated the Java language project. The primary goal was to design a language for digital devices like set-top boxes and interactive televisions.

###  From 'Oak' to 'Java' (1995)
* Initially named **Oak** after an oak tree that stood outside James Gosling's office.
* Later renamed to **Java** (inspired by Java coffee from Indonesia) because "Oak" was already a registered trademark.

### The WORA Concept
Java introduced the revolutionary idea of **"Write Once, Run Anywhere"** using the Java Virtual Machine (JVM), making software platform-independent.

### 1.What is Java☕?

->Java is a high-level,general-purpose programming language used to develop web applications,mobile applications,desktop software, and enterprise systems.
->Java is well known for its platform independence.Java bytecode can run on different platforms that support a Java Virtual Machine (JVM).
->Its famous principle is "Write Once, Run Anywhere" (WORA).

### 2. Who Developed Java📝?

->Java was developed at Sun Microsystems as part of the Green Project.
->The members of the original development team included:

⁑James Gosling: Lead developer,widely known as the (Father of Java).

⁑Patrick Naughton: An important member of the original development team.

⁑Mike Sheridan: A member of Green Project team.

### 3.Development Years of Java📅:

->Java development began in 1991 and the language was officially introduced in 1995.

⁂1991: The Green Project began.

⁂1991-1995: The language was developed and refined.

⁂1995: Java was publicly announced.

Initially,the project focused on software for consumer electronic devices.Java later became widely used in web and enterprise software development.

### 4.Earlier Names of Java🕐:

->Java was not the language's original name.

⁜Green Talk: An early name associated with the project.

⁜Oak: The original name of the programming language.

⁜Java: The name adopted later,after a trademark conflict prevented continued use of Oak.

The name Java was inspired by Java coffee and is not an abbreviation.

### 5.Inspiration Behind Java📌:

->Java's syntax was influenced by C and C++. Some concepts from Smalltalk also influenced its design.
->The Inspiration language of java is Microsoft Visual Basic.
->The developers aimed to create a language suitable for different computing environment.

### 6.Released Company🧑‍💻:

->Java was developed and introduced by Sun Microsystems,Inc.in 1995.
->In 2010, Oracle Corporation acquired Sun Microsystems and continued the development of Java.

### 7.Java Symbol☕:

Java is popularly represented by a steaming coffee cup☕. The coffee-related name and symbol have become widely recognized parts of java's identity.

### 8.Java Development Timeline🕰️:

⁑1991: Green Project started.
⁑1991-1995: Java Language development.
⁑1995: Java was publicly introduced.
⁑2010: Oracle acquired Sun Microsystems.
