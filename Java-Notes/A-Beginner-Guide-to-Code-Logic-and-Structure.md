## What is Program?
 👉 A Program is a set of instructions given to a computer to perform a specific task.(Just as we follow a recipe to cook a food),as well as a computer follows program instructions to get a result.

## The Role of Logic:
   💫Logic represents the step-by-step instructions to solve a problem.
   💫Logic is a most Important part of Programming.
   💫Before writing code, you need to find the logic to solve the program.
   
## The Key Building Blocks of Code:
  👇 We Use three fundamental elements:
          📌  Variables (Containers) : Variables act as containers used to store values/data in memory.
          📌  Values (Data) : Values represent the actual data or information stored inside a variable.
          📌  Data Types (Type of Values) : Data Types define the type and category of the value.The common types of data types are:
                                🔆Integer
                                🔆 Floating Point (Float/Double) 
                                🔆 Character
                                🔆 Boolean
                                🔆 String
                     Example:
                        [Variable]=[Value] ( of a specific[Data Type]) => [Logic]
                                     int age = 20;
                                     'int' is Datatype
                                     'age' is Variable
                                     '20' is Value

 ## Mastering  these three basics-Logic,Variables,Values, and Data Types makes learning java or any other language much easier!!🚀
